# 需求规格说明书（PRD）

| 项 | 内容 |
|----|------|
| 项目名称 | 股票复盘日记本 |
| 版本 | v1.0 |
| 状态 | 开发中 |
| 最后更新 | 2026-07-23 |

> 变更历史见 [需求变更记录.md](./需求变更记录.md)

---

## 1. 项目背景

个人股票复盘日记，记录每日/每次交易思考。支持华为鸿蒙手机 PWA 与电脑 Web 端数据同步，部署于腾讯云轻量服务器，仅授权用户可访问。

## 2. 用户与角色

| 角色 | 说明 | 权限 |
|------|------|------|
| admin | 种子管理员 | 登录、写日记、审核用户（首版可隐藏）、登出 |
| user | 审核通过用户 | 登录、写日记、查询自己的日记、登出 |

**首版约束**：当前仅 1 人使用，`OPEN_REGISTRATION=false`，不开放公开注册。

## 3. 功能需求

### 3.1 认证

- 统一登录页（无 admin 专用入口说明文案）
- JWT 鉴权，顶栏「退出」清除会话
- 首版：仅 admin 种子账号可登录

### 3.2 复盘日记字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 展示自动加粗，无默认「今日复盘」前缀 |
| 复盘日期 | 是 | 查询主维度 |
| 当日盈亏 | 否 | 元，红涨绿跌 |
| 总盈亏 | 否 | 账户累计，红涨绿跌 |
| 情绪 | 否 | 表情点选：😌😰🤑😨😐 |
| 大盘概况 | 否 | 自动读取，可折叠，默认收起 |
| 正文 | 否 | 富文本；列表/插图在光标处插入 |
| 股票 | 自动 | 正文输入代码自动标签化，无手动选股 |

### 3.3 大盘概况

**指数**：上证、深证成指、创业板、科创50  
**扩展**：涨跌家数、成交额、大盘资金净流入  
**取数**：

| 场景 | 数据 |
|------|------|
| 当天且 15:00 前 | 盘中快照 |
| 当天已收盘 / 历史日 | 收盘数据 |

**交互**：▶ 三角折叠，默认收起；收起时一行摘要

### 3.4 正文编辑器

- TipTap 富文本
- 股票代码自动标签化（对照本地代码库）
- 插图：光标处插入，非固定底部占位
- 列表：正文内项目符号

### 3.5 查询

- 按日期范围
- 按股票代码（关联 diary_stocks）
- 列表按 entry_date 倒序

### 3.6 图片

- JPG / PNG / WebP，≤ 5MB
- 存服务器 `uploads/{userId}/`

### 3.7 入口规范

| 操作 | 入口 |
|------|------|
| 新建 | 底部 Tab「写复盘」 |
| 保存 | 编辑页底部按钮 |
| 编辑/删除 | 详情页底部 |

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 终端 | 手机优先 PWA + 响应式 Web |
| 部署 | Docker Compose + 腾讯云轻量 |
| 安全 | HTTPS（上线）、bcrypt、JWT |
| 行情源 | 东方财富等免费接口，服务端代理 |
| 代码库 | 静态入库，脚本定期更新 |

## 5. 首版不做

- 原生 App、离线冲突合并
- 评分/标签、个股/K 线行情
- 腾讯云 COS、公开注册（首版关闭）

## 6. 验收标准

1. admin 登录 → 新建复盘（大盘自动、正文插图、代码自动标签）→ 保存
2. 手机/电脑数据一致
3. 按日期、股票代码筛选正确
4. 大盘可折叠，默认收起
5. PWA 可添加桌面
6. **交付前完成 [自测文档](../testing/自测文档.md) 全部必测项**
