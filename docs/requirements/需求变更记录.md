## 变更申请模板

复制以下模板追加新行：

```markdown
| YYYY-MM-DD | CHG-0XX | 【变更描述】 | 【原因/提出人】 | 【模块】 | 待确认/已确认/已实现 |
```

### 变更流程

1. 提出变更 → 写入本表，编号递增
2. 评审确认 → 状态改为「已确认」
3. 更新 [需求规格说明书](./需求规格说明书.md) 对应章节
4. 开发实现 → 状态改为「已实现」
5. 更新 [自测文档](../testing/自测文档.md) 如有新测项
