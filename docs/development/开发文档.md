## 4. 本地开发

### 4.1 环境要求

- Node.js ≥ 20
- Docker Desktop（PostgreSQL）
- pnpm 或 npm

### 4.2 启动步骤

**推荐（有 Docker）：**

```bash
cp .env.example .env
docker compose up -d postgres
npm install
cd apps/api && npx prisma migrate deploy && npm run db:seed && npm run dev
# 另开终端
npm run dev:web
```

**无 Docker 时：**

```bash
# 终端 1：嵌入式 Postgres（需在本机终端运行，勿在受限沙箱）
npm run dev:db

# 终端 2
cd apps/api && npx prisma migrate deploy && npm run db:seed && npm run dev

# 终端 3
npm run dev:web
```

- Web: http://127.0.0.1:5173
- API: http://127.0.0.1:3000/api/health
- 账号: `admin` / `ChangeMe_Admin_2026`
### 4.3 环境变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `DATABASE_URL` | PostgreSQL 连接串 | `postgresql://...` |
| `JWT_SECRET` | JWT 密钥 ≥32 字符 | 随机字符串 |
| `ADMIN_USERNAME` | 种子管理员 | `admin` |
| `ADMIN_PASSWORD` | 种子密码 | 部署后修改 |
| `OPEN_REGISTRATION` | 是否开放注册 | `false`（首版） |

## 5. 开发规范

### 5.1 分支

- `main`：稳定可部署
- `cursor/*`：功能开发分支

### 5.2 提交信息

```
<type>: <简述>

type: feat | fix | docs | refactor | test | chore
```

### 5.3 代码约定

- TypeScript strict
- API 错误统一 `{ error, code }`
- 前端 A 股配色：红涨绿跌
- 手机优先响应式

## 6. 模块开发顺序

1. 脚手架 + Docker + Prisma 迁移
2. 鉴权（admin 种子、JWT、登出）
3. 日记 CRUD + 筛选
4. 大盘行情抓取 + 折叠 UI
5. TipTap 编辑器（标签化、光标插图）
6. PWA + 移动端
7. **自测 → 修复 BUG → 再自测**
8. 部署（域名 + HTTPS）
