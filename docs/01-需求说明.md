# 01 — 需求说明

## 1. 项目背景

个人股票复盘日记本，用于记录每日/每次交易复盘。需要支持手机（华为鸿蒙）与电脑 Web 端数据同步，部署在腾讯云轻量应用服务器上，仅授权用户可访问。

## 2. 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| 管理员 (admin) | 系统初始账号，负责审核新用户 | 登录、写日记、审核/拒绝注册、查看用户列表 |
| 普通用户 (user) | 经管理员审核通过的用户 | 登录、写日记、查询自己的日记 |

## 3. 功能需求

### 3.1 账号体系

- **注册**：填写用户名、密码、确认密码；提交后状态为「待审核」，不可登录
- **登录**：仅 `active` 状态用户可登录；`pending` 提示等待审核；`rejected` 提示已被拒绝
- **管理员审核**：管理员在后台查看待审核列表，可「通过」或「拒绝」
- **默认管理员**：首次部署通过环境变量创建，用户名 `admin`；**与普通用户同一登录页**，`role=admin` 登录后显示「管理」Tab
- **登出**：各页顶栏「退出」，清除 JWT，跳转登录页

### 3.2 复盘日记

每条日记包含：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 标题 | 文本 | 是 | 前端展示自动加粗 |
| 复盘日期 | 日期 | 是 | 查询主维度，默认当天 |
| 股票 | 自动提取 | 否 | **正文内输入代码后自动标签化**；对照代码库补全名称；用于查询。**无单独选股控件** |
| 当日盈亏 | 数值 | 否 | 单位元，可正可负；红涨绿跌 |
| 总盈亏 | 数值 | 否 | 账户累计盈亏，可正可负；红涨绿跌 |
| 情绪 | 表情枚举 | 否 | **点选表情**，非输入 |
| 大盘概况 | 自动读取 | 否 | 按**复盘日期**拉取四大指数：上证、深证、创业板、科创50；展示点位与涨跌（红涨绿跌） |
| 正文 | 富文本 | 否 | 操作回顾、反思等；列表/图片/股票代码自动标签化 |

**已去掉**：评分、标签、手动选股、正文手打大盘概况。

### 3.3 大盘概况（自动读取）

- 选择复盘日期后，自动请求该日四大指数数据：
  - 上证指数、深证成指、创业板指、科创50
- **取数规则**（按复盘日期 + 当前时刻）：

| 场景 | 取数 | 展示标签 |
|------|------|----------|
| 复盘日期 = **今天**，且 **15:00 收盘前** | **当前盘中快照**（实时点位与涨跌） | `YYYY-MM-DD 盘中快照` |
| 复盘日期 = 今天，已收盘 | 当日收盘数据 | `YYYY-MM-DD 收盘` |
| 复盘日期 = **历史日期** | 该日收盘数据 | `YYYY-MM-DD 收盘` |

- 展示：
  - **四大指数**：名称、点位、涨跌额、涨跌幅（红涨绿跌）
  - **涨跌家数**：跌 / 涨 对比条 + 家数（如 2780 : 2489）
  - **成交额**：当日全市场成交额（亿）
  - **大盘资金净流入**：净流入金额（亿），正红负绿
- 只读区块，不需手打；保存时写入 `marketSnapshot`（含 `snapshotType`: `intraday` | `close`、`snapshotAt` 时间戳）
- 数据源：服务端代理第三方行情接口；盘中调实时接口，历史/收盘调日线接口
- **不做**：个股实时价、K 线自动拉取

### 3.4 股票代码自动标签化

- 用户在正文直接输入如 `600519`
- 与内置/外接 **股票代码库** 匹配成功后，自动变为行内标签（展示代码 + 名称，如 `600519 贵州茅台`）
- 保存时从正文提取去重股票列表，供「按股票代码查询」
- **不提供**单独的「选择股票」表单；避免二次选择
- 双击标签可还原为纯代码（改错时）
- 首版代码库：服务端静态 A 股表；不做实时行情

### 3.5 查询与筛选

- **按日期**：单日选择，或日期范围（起止）
- **按股票代码**：匹配日记中任意关联股票（代码或名称）
- **列表排序**：默认按复盘日期倒序

### 3.6 图片

- 在富文本编辑器内插入图片（本地上传）
- 支持 JPG / PNG / WebP，单张 ≤ 5MB

### 3.7 多端同步

- 手机：鸿蒙浏览器访问 Web，可「添加到桌面」作为 PWA
- 电脑：同一 URL，响应式布局

### 3.8 入口与操作（避免重复）

| 操作 | 入口 |
|------|------|
| 新建复盘 | **仅**底部 Tab「写复盘」（手机）；桌面顶栏一个「写复盘」 |
| 保存 | **仅**编辑页底部大按钮（无顶栏保存） |
| 编辑/删除 | **仅**详情页底部（无顶栏编辑） |

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 部署 | 腾讯云轻量应用服务器，Docker Compose；**域名已有，最后阶段绑定 HTTPS** |
| 安全 | HTTPS、密码 bcrypt、JWT |
| 可用性 | 手机优先，触控热区 ≥ 44px |

## 4.1 已确认的外部依赖（2026-07-23）

| 项 | 决策 |
|----|------|
| 域名 / 备案 | 已有，部署阶段再绑定 |
| 行情数据 | **方案 A**：服务端代理免费公开接口（如东方财富），无需注册第三方 API |
| 股票代码库 | **静态 JSON 冗余**入库，脚本定期更新（无需 Tushare 等 Token） |
| 使用人数 | **当前 1 人**；保留 admin 种子账号，**首版关闭公开注册**（`OPEN_REGISTRATION=false`） |
| 图片存储 | 服务器本地磁盘 `uploads/` |
| Git 远程仓库 | 晚些提供，本地先开发 |

## 5. 首版不做

- 原生鸿蒙 / 安卓安装包
- 离线编辑与冲突合并
- 实时行情 / K 线自动拉取（**四大指数大盘概况除外**）
- 评分、标签字段
- 腾讯云 COS（后续可迁）

## 6. 验收标准

1. 注册 → 管理员审核 → 登录 → 新建日记（含自动大盘概况、正文插图）→ 多端可见
2. 按日期、股票代码能筛到对应日记
3. 标题加粗；无评分/标签；入口无重复按钮
4. PWA 可添加到鸿蒙桌面
5. Docker Compose 一键启动
