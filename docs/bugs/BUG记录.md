## 登记模板

```markdown
| BUG-001 | YYYY-MM-DD | P1 | 编辑器 | 【简述】 | 1.… 2.… | 待修复 | | |
```

### 状态流转

`待确认` → `待修复` → `已修复待验证` → `已关闭` → （若复发）`重新打开`

---

## 与自测联动

1. 自测失败项 → 登记 BUG，关联自测 ID（如 DIARY-03）
2. 修复后 → 状态改「已修复待验证」
3. 回归自测通过 → 状态改「已关闭」，填写修复版本/提交号
