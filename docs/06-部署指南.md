# 06 — 部署指南（腾讯云轻量）

## 1. 服务器要求

| 项 | 建议 |
|----|------|
| 规格 | 2核 2GB 及以上 |
| 系统 | Ubuntu 22.04 LTS |
| 磁盘 | ≥ 40GB（含图片存储） |
| 端口 | 开放 80、443 |

## 2. 前置准备

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装 Docker Compose 插件（通常已随 Docker 安装）
docker compose version
```

## 3. 部署步骤

```bash
# 1. 克隆代码到服务器
git clone <your-repo> /opt/stock-diary
cd /opt/stock-diary

# 2. 配置环境变量
cp .env.example .env
nano .env
```

**.env 示例**

```env
# 数据库
POSTGRES_USER=diary
POSTGRES_PASSWORD=<强密码>
POSTGRES_DB=stock_diary

# JWT（至少 32 位随机字符串）
JWT_SECRET=<随机字符串>

# 管理员（首次部署创建）
ADMIN_USERNAME=admin
ADMIN_PASSWORD=ChangeMe_Admin_2026

# 域名（HTTPS 用）
DOMAIN=diary.example.com
```

```bash
# 3. 启动
docker compose up -d

# 4. 查看日志
docker compose logs -f
```

## 4. Docker Compose 服务

| 服务 | 说明 |
|------|------|
| postgres | 数据库，数据持久化到 volume |
| api | Fastify 后端，自动 migrate + seed |
| web | Nginx 托管前端静态文件 |
| nginx | 反向代理，HTTPS 终结 |

## 5. HTTPS（推荐）

使用 Certbot + Let's Encrypt：

```bash
# 在 nginx 配置中预留 acme-challenge 路径
certbot certonly --webroot -w /var/www/certbot -d diary.example.com
```

证书自动续期可加入 crontab。

> PWA 与 JWT 在生产环境**必须**使用 HTTPS。

## 6. 鸿蒙手机使用

1. 浏览器打开 `https://diary.example.com`
2. 登录账号
3. 浏览器菜单 → **添加到桌面**
4. 桌面图标打开即为全屏 PWA

## 7. 运维

```bash
# 备份数据库
docker compose exec postgres pg_dump -U diary stock_diary > backup.sql

# 备份图片
tar czf uploads-backup.tar.gz ./uploads

# 更新版本
git pull
docker compose up -d --build
```

## 8. 默认管理员

| 字段 | 值 |
|------|-----|
| 用户名 | admin |
| 初始密码 | ChangeMe_Admin_2026 |

**首次登录后请立即修改密码。**

管理员职责：

1. 登录系统
2. 进入「管理」→「用户审核」
3. 对新注册用户点击「通过」或「拒绝」

## 9. 故障排查

| 现象 | 排查 |
|------|------|
| 502 Bad Gateway | `docker compose ps` 检查 api 是否 healthy |
| 无法登录 | 检查用户 status 是否为 active |
| 图片无法显示 | 检查 uploads 卷挂载与 nginx 路径 |
| PWA 无法安装 | 确认 HTTPS 有效、manifest 可访问 |
